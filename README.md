# ♟️ Simple Chess Strategy Game (C Language)

โครงสร้างโปรเจกต์เกมกระดานเชิงกลยุทธ์ขนาดเล็ก พัฒนาด้วยภาษา C โดยใช้ระบบ Turn-based และมีกลไกการปะทะกันแบบ Rock-Paper-Scissors (ค้อน-กรรไกร-กระดาษ)

---

## 📋 รายละเอียดโปรเจกต์ (Overview)
เกมนี้เป็นเกมกระดานขนาด 5x5 ที่ผู้เล่นสองคน (**Player A** และ **Player B**) จะต้องควบคุมตัวหมากของตนเองเพื่อกำจัดตัวหมากของฝ่ายตรงข้ามให้หมด หรือเล่นจนครบจำนวน Turn ที่กำหนด (20 Turns) โดยมีระบบสุ่มทำลายหมาก (Random Skill) ทุกๆ 3 รอบเพื่อเพิ่มความท้าทาย

## 🛠 โครงสร้างระบบ (Architecture)

### 1. การจัดการข้อมูลกระดาน (Board Management)
ระบบใช้ Array 2 มิติ ขนาด 5x5 จำนวน 3 ชุดในการแยกสถานะออกจากกันเพื่อความง่ายในการตรวจสอบเงื่อนไข:
* `board_A`: เก็บพิกัดหมากของผู้เล่น A (`J`, `K`, `Q`)
* `board_B`: เก็บพิกัดหมากของผู้เล่น B (`j`, `k`, `q`)

### 2. กลไกการเล่น (Game Logic)
* **ระบบ Turn-based:** สลับผู้เล่นโดยใช้ตัวแปร `player` (0 สำหรับ A, 1 สำหรับ B)
* **การเคลื่อนที่:** รองรับการเดิน 4 ทิศทาง (W, A, S, D) โดยมีการรับ Input และแปลงเป็นอักษรตัวเล็กเพื่อลดข้อผิดพลาด
* **ระบบการต่อสู้ (Combat System):** 0ใช้หลักการเปรียบเทียบประเภทตัวหมาก (Hierarchical Logic):
    * `K` (King) ชนะ `Q` (Queen)
    * `Q` (Queen) ชนะ `J` (Jack)
    * `J` (Jack) ชนะ `K` (King)
    * **Draw:** หากตัวหมากประเภทเดียวกันปะทะกัน ทั้งคู่จะถูกลบออกจากกระดาน (Mutual Destruction)

### 3. ระบบสุ่มสถานการณ์ (Random Events)
ในทุกๆ รอบที่หารด้วย 3 ลงตัว (`turn % 3 == 0`) ระบบจะทำการสุ่มพิกัด (Row, Col) และทำลายหมากที่อยู่ในตำแหน่งนั้นทันที เปรียบเสมือน Skill จากฟ้าที่ผู้เล่นควบคุมไม่ได้

---

## 🎮 วิธีการเล่น (How to Play)

1. **เลือกตัวหมาก:** ระบุพิกัด `row` (แถว) และ `col` (หลัก) ตั้งแต่ 0-4
2. **ระบุทิศทาง:** ใส่คำสั่งการเดิน:
    * `w` : ขึ้น (Up)
    * `s` : ลง (Down)
    * `a` : ซ้าย (Left)
    * `d` : ขวา (Right)
